# Futbol Wordle

Günlük futbolcu tahmin oyunu. Gizli futbolcuyu, kariyerindeki kulüplerden yola çıkarak 6 tahminde bul.

- **Günlük mod:** Herkes aynı gün aynı oyuncuyu görür, sonuç paylaşılabilir.
- **Serbest mod:** Kolay / zor seçimi ve oyuncu havuzu (beş büyük lig, Süper Lig, Şampiyonlar Ligi, efsaneler, güncel).

Tek bir `index.html` dosyası; kütüphane ya da build adımı yok. Oyuncu verisi dosyanın başındaki `OYUNCULAR` dizisinde.
